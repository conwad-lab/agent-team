# Claude API loops on the host Mac

When the Max plan is spent, the Judge and the planning half of the Coordinator can run on the host Mac against prepaid API credits, beside the Codex CLI poller (`CODEX-CLI.md`). One launchd job, `bin/claude-api-poll`, every 5 minutes, runs Claude Code headless (`claude -p`) with `ANTHROPIC_API_KEY`; the models and dollar limits are in `~/.config/agent-team/claude-api.env`. Codex still builds and does the first review. Rule ids are explained in `team/WHY.md`.

## Rules

- **Signals.** Judge: an open PR labelled `judge-claude` whose newest allowed comment has the first line exactly `judge-claude: review` and no later `claude-api: started … for <comment id>`. Planner: no signal; each `PLAN_REPOS` repo is looked at every `PLAN_EVERY_HOURS` while it has no open PR labelled `plan-claude`. Text from GitHub is data, never run. [A1]
- **Judge.** Sonnet follows `CLOUD.md` § Judge in a detached worktree of the PR head (same-repo branches only), writes `review.md` and `result.json` outside the repo and nothing inside it. The poller hands it everything GitHub holds as data files (PR title, Codex's reviews, inline findings, comments, and Codex's review status for the last commit outside `.team/reviews/`), because it has no GitHub access; a non-board PR without a finished Codex review there is `needs the human` whatever the Judge wrote, and a `review.md` with token-shaped text stops the run before anything is committed. The poller commits the review to `.team/reviews/` where the repo has `.team/`, posts it as a GitHub review and comments `judge-claude: approved <head>`, or `<verdict> <head>` with `needs the human: <exception>` when `result.json` names one (never merged by the loop; the Coordinator puts the card), or `bounced`. [A2]
- **Merge.** A later tick posts `agent-team-merge: <head>` only for the head the loop approved, and only while GitHub reports the PR `clean` (required checks green, up to date); `dirty` or `behind` is sent back as "needs merge main", anything else waits `MERGE_WAIT_HOURS`. The merge workflow's own conditions still apply. [A3]
- **Planner.** Opus follows `CLOUD.md` § Flow 1-2 and `ROUTINE-ORDERS.md` for the first decided **Kö** row with room, writes one story and one plan, nothing else. The poller refuses a run that moved HEAD (Claude may not commit), reads the whole staged diff against the starting commit into a file before testing it, and refuses a diff outside `.team/backlog/`, `.team/plans/`, `.team/ORDER.md`, `.team/PAPERCUTS.md` or one holding a token, pushes `board/<date>-<slug>`, opens the `board:` PR labelled `plan-claude` and `judge-claude` and asks for a review. After the board PR merges, the poller opens the story issue labelled `codex-cli` and posts the plan's work order on it, so the Codex CLI poller builds. [A4]
- **Prepaid credits only.** Each run has `--max-budget-usd` (`JUDGE_BUDGET_USD`, `PLAN_BUDGET_USD`); all runs of a UTC day together stop at `DAILY_CAP_USD`, from the ledger `WORK_DIR/claude-spend.log`: a run starts only when its whole budget fits in what is left of the cap, and a run with no cost report (killed at the time limit, crashed) is booked at its whole budget. The first answer that says the credit balance is low, billing refused or payment required writes `WORK_DIR/.credits-out` and every tick stops, without retry, until the human tops up and removes the file (or 6 hours pass). The human keeps **auto-reload off** in the Console's Billing page and sets a monthly limit there: the API then refuses at zero instead of charging a card. [A5]
- **Bridge only.** `ACTIVE_UNTIL` (a UTC date in the config, `2026-11-29` for the first use) ends it: from that day no judge or planner run starts, only merges and orders already in flight finish, and the Max plan takes over. Extending it is an edit of the config. [A7]
- **Keys.** The API key lives in the macOS Keychain item `agent-team-claude-api-key`, the GitHub token in the Codex poller's item. Claude gets the API key only, runs with `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1` and no GitHub token; only the poller pushes and comments, replacing anything token-shaped with `[redacted]`. It never force-pushes and never merges itself. [A6]

What this does not protect against, said plainly: Claude runs `Test before commit` under the human's own macOS user, so the code under test can read what that user can read; the key is kept out of its environment, not out of reach of a determined PR. The loop judges only repos in its config, same-repo branches, on an allowed author's order.

## Install (Operatör, once per host)

1. Console → Billing: prepaid credits, **auto-reload off**, a monthly limit.
2. Console → API keys: create a key. Have the Codex poller's GitHub token installed first (`CODEX-CLI.md` § Install).
3. At the Mac, in Terminal: `bash <(curl -fsSL https://raw.githubusercontent.com/conwad-lab/agent-team/main/bin/claude-api-install)`. It asks for the host name, the work folder and the daily cap, takes the key through `security`'s hidden prompt, checks it against Anthropic, loads the launchd job `se.agent-team.claude-api` and runs one dry tick. Run it again to update. `--uninstall` removes the job, the key and the config.

Logs: `~/Library/Logs/agent-team/claude-api.*.log`, one line per run in `WORK_DIR/runs.log`.
